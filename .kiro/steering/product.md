# Product Overview

Debre Mihret Kidus Gebriel Ethiopian Orthodox Tewahedo Church website — a bilingual (English/Amharic) static site for the Ethiopian Orthodox community in Christchurch, New Zealand.

## Purpose

Serve as the church's online presence with service times, about information, news/blog, gallery, donation details, and contact information. Associated with "Finote Hiwot Sunday School."

## Key Features

- Bilingual content in English (en) and Amharic (am) with prefix-based routing
- Blog with content management via Decap CMS
- Mahber (fellowship groups) directory
- Browser-based locale detection and preference storage
- SEO: sitemap generation, structured data (LocalBusiness, BlogPosting schemas)
- Deployed to Netlify as a static site
